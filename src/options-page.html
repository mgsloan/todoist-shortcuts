Keyboard shortcuts

Enter one shortcut per line. Use spaces between keys in a sequence (for example ; n) and + for held modifiers (for example ctrl+e). Leave a field empty to disable an action. Reset edits the form; use Save shortcuts to apply your changes.

Escape and the specialized navigation hints, bulk-move picker and dialog confirmation controls remain fixed. Browser and operating-system shortcuts can also take precedence over extension shortcuts.
